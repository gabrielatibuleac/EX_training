# EX_training
Bine ați venit la training-ul departamentului IT!

Exerciții
Clonează repository-ul local.

Creează un branch cu denumirea <pseudonim>/feature-v1 și urcă-l pe GitHub.

Hint: dacă te numești Alexandru Frunză, ai putea crea un branch cu numele afrunza/feature-v1.
Creează un fișier cu numele tău, scrie cel puțin două linii în fișier și urcă modificările pe GitHub.

Creează un nou branch cu denumirea <pseudonim>/feature-v2, modifică a doua linie din fișierul tău și urcă schimbările pe GitHub.

Revino la branch-ul <pseudonim>/feature-v1 și modifică a doua linie din fișierul tău în mod diferit față de pasul 4 (pentru a genera un conflict într-un pas următor).

Unește schimbările din branch-ul <pseudonim>/feature-v2 în branch-ul <pseudonim>/feature-v1 (păstrează ambele modificări, pe linii diferite), apoi urcă noile schimbări pe GitHub.

Așteaptă ca toți colegii să finalizeze primii 6 pași.

Unește schimbările din branch-ul tău cu cele din branch-ul unui coleg folosind funcționalitatea de Pull Request de pe GitHub.
